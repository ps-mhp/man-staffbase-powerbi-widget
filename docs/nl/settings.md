# Instellingen

Alle instellingen staan in het venster **Rapport insluiten**, waarmee je de
widgetinstellingen opent. Het bestaat uit drie secties.

| Instelling (sectie) | Beschrijving |
| --- | --- |
| Power BI-link (inhoud) | Verplicht. Insluitlink (`https://app.powerbi.com/reportEmbed?…`), de volledige `<iframe>`-Code oder die Adresse eines geöffneten Berichts. Auch „Im Web veröffentlichen“-Links (`/view?r=…`), Dashboards und paginierte Berichte gehen. Nur Adressen von Power BI werden angenommen. |
| Titel für Screenreader (Barrierefreiheit) | Name des Berichts für Screenreader, auf der Seite unsichtbar. Voreingestellt: „Power-BI-Bericht“. |
| Seitenverhältnis (Gestaltung) | Breite zu Höhe des Berichtsbereichs: 16:9 (voreingestellt), 4:3, 3:2, 21:9, 1:1 oder 9:16 (Hochformat). |

Blöcke, die vor dem Fenster angelegt wurden, behalten ihre Werte: Sie gelten
weiter, bis sie im Fenster geändert und übernommen werden.
</iframe>
