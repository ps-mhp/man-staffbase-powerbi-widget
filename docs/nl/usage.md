# Stap voor stap

## Rapport insluiten

1. Open het rapport in Power BI (app.powerbi.com).
2. Kies **Bestand › Rapport insluiten › Website of portaal**.
3. Kopieer de weergegeven link. Je kunt ook de volledige `<iframe>`-Code
   darunter oder die Adresse des geöffneten Berichts aus der Adresszeile.
4. Im CMS das Widget **Power BI** auf der Seite platzieren.
5. Im Feld **Power-BI-Link** den kopierten Link einfügen.
6. Optional **Titel (für Screenreader)** und **Seitenverhältnis** anpassen.
7. Speichern und in der Vorschau prüfen.

## Bestimmte Berichtsseite zeigen

1. In Power BI die gewünschte Seite des Berichts öffnen.
2. Die Adresse aus der Adresszeile des Browsers kopieren (sie endet auf
   `/ReportSection…`).
3. Diese Adresse in **Power-BI-Link** einfügen — das Widget öffnet den Bericht
   dann auf dieser Seite.
