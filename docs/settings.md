# Einstellungen

| Einstellung | Beschreibung |
| --- | --- |
| Power-BI-Link | Pflicht. Einbettungslink (`https://app.powerbi.com/reportEmbed?…`), der ganze `<iframe>`-Code oder die Adresse eines geöffneten Berichts. Auch „Im Web veröffentlichen“-Links (`/view?r=…`), Dashboards und paginierte Berichte gehen. Nur Adressen von Power BI werden angenommen. |
| Titel (für Screenreader) | Name des Berichts für Screenreader, auf der Seite unsichtbar. Voreingestellt: „Power-BI-Bericht“. |
| Seitenverhältnis | Breite zu Höhe des Berichtsbereichs: 16:9 (voreingestellt), 4:3, 3:2, 21:9, 1:1 oder 9:16 (Hochformat). |
