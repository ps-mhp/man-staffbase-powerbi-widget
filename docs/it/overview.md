# Power BI

Il widget visualizza un report di Power BI direttamente sulla pagina. È sufficiente
il link di incorporamento del report da Power BI; i dati, i filtri e le pagine del
report rimangono in Power BI e sono sempre aggiornati.

## Cosa vedono i lettori

Il report a tutta larghezza di colonna, con le proporzioni selezionate, utilizzabile
come in Power BI (filtri, pagine, schermo intero). Power BI verifica le
autorizzazioni: chi non è autorizzato a visualizzare il report in Power BI, vedrà anche qui
solo la schermata di accesso o il messaggio di errore di Power BI. Al primo accesso potrebbe essere necessario
effettuare l’accesso con l’account aziendale.

## Cosa vedete nell’editor CMS

La stessa cosa dei lettori; la modifica avviene nella finestra a schermo intero **Incorpora
report**. Se il link manca o non è valido, al posto
del report appare un messaggio grigio con la motivazione.
