# Domande frequenti

**Domanda:** “Nessun collegamento Power BI configurato. Inserire il collegamento di incorporamento del report nelle impostazioni del widget.”

Risposta: Il campo **Link Power BI** nella finestra **Incorpora report** è vuoto. Inserire il link come descritto nella sezione «Passo dopo passo».

**Domanda:** «Il link non rimanda a Power BI. Sono consentiti solo link a app.powerbi.com (o ai cloud di Power BI per le autorità pubbliche e la Cina).»

Risposta: Per motivi di sicurezza, il widget mostra solo contenuti provenienti da Power BI. Verificare che il link inizi con `https://app.powerbi.com/` e che sia stato copiato per intero.

**Domanda:** «Il link non può essere incorporato. Selezionare in Power BI “File › Incorpora report › Sito web o portale” e inserire il link visualizzato in quella schermata.»

Risposta: Il link porta sì a Power BI, ma non a un report (ad es. la pagina iniziale o un link di condivisione `/links/…`). Utilizzare il link di incorporamento dal menu **File › Incorpora report**.

**Domanda:** Al posto del report compare una schermata di accesso o il messaggio «Accesso negato».

Risposta: Ciò è dovuto a Power BI stesso. I lettori devono disporre di una licenza Power BI e dei diritti di lettura sul report o sull’area di lavoro. Assegnare i diritti in Power BI, non nel CMS.

**Domanda:** Il report presenta bordi grigi o è troppo piccolo.

Risposta: Nella finestra **Incorpora report**, alla voce **Proporzioni**, selezionare il formato corrispondente a quello della pagina del report in Power BI (di solito 16:9).
