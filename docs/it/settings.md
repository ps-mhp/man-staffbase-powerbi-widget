# Impostazioni

Tutte le impostazioni si trovano nella finestra **Incorpora report**, che
apre le impostazioni del widget. È suddivisa in tre sezioni.

| Impostazione (Sezione) | Descrizione |
| --- | --- |
| Link Power BI (Contenuto) | Obbligatorio. Link di incorporamento (`https://app.powerbi.com/reportEmbed?…`), che contiene l'intero `<iframe>`-Code oder die Adresse eines geöffneten Berichts. Auch „Im Web veröffentlichen“-Links (`/view?r=…`), Dashboards und paginierte Berichte gehen. Nur Adressen von Power BI werden angenommen. |
| Titel für Screenreader (Barrierefreiheit) | Name des Berichts für Screenreader, auf der Seite unsichtbar. Voreingestellt: „Power-BI-Bericht“. |
| Seitenverhältnis (Gestaltung) | Breite zu Höhe des Berichtsbereichs: 16:9 (voreingestellt), 4:3, 3:2, 21:9, 1:1 oder 9:16 (Hochformat). |

Blöcke, die vor dem Fenster angelegt wurden, behalten ihre Werte: Sie gelten
weiter, bis sie im Fenster geändert und übernommen werden.
</iframe>
