# Configuración

Todas las opciones de configuración se encuentran en la ventana **Incrustar informe**, que
abre la configuración del widget. Consta de tres secciones.

| Opción (sección) | Descripción |
| --- | --- |
| Enlace de Power BI (contenido) | Obligatorio. Enlace de incrustación (`https://app.powerbi.com/reportEmbed?…`), que contiene todo el `<iframe>`-Code oder die Adresse eines geöffneten Berichts. Auch „Im Web veröffentlichen“-Links (`/view?r=…`), Dashboards und paginierte Berichte gehen. Nur Adressen von Power BI werden angenommen. |
| Titel für Screenreader (Barrierefreiheit) | Name des Berichts für Screenreader, auf der Seite unsichtbar. Voreingestellt: „Power-BI-Bericht“. |
| Seitenverhältnis (Gestaltung) | Breite zu Höhe des Berichtsbereichs: 16:9 (voreingestellt), 4:3, 3:2, 21:9, 1:1 oder 9:16 (Hochformat). |

Blöcke, die vor dem Fenster angelegt wurden, behalten ihre Werte: Sie gelten
weiter, bis sie im Fenster geändert und übernommen werden.
</iframe>
