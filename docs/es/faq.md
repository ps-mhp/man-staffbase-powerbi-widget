# Preguntas frecuentes

**Pregunta:** «No hay ningún enlace de Power BI configurado. Introduce el enlace de incrustación del informe en la configuración del widget».

Respuesta: El campo **Enlace de Power BI** está vacío. Introduce el enlace tal y como se describe en «Paso a paso».

**Pregunta:** «El enlace no lleva a Power BI. Solo se permiten enlaces a app.powerbi.com (o a las nubes de Power BI para organismos públicos y China)».

Respuesta: Por motivos de seguridad, el widget solo muestra contenidos de Power BI. Comprueba si el enlace comienza por `https://app.powerbi.com/` y si se ha copiado en su totalidad.

**Pregunta:** «No se puede incrustar el enlace. Selecciona en Power BI “Archivo › Incrustar informe › Sitio web o portal” e introduce el enlace que aparece allí».

Respuesta: El enlace conduce a Power BI, pero no a un informe (por ejemplo, la página de inicio o un enlace para compartir `/links/…`). Utilice el enlace de incrustación del menú **Archivo › Incrustar informe**.

**Pregunta:** En lugar del informe, aparece una pantalla de inicio de sesión o el mensaje «Sin acceso».

Respuesta: Esto se debe a Power BI. Los lectores necesitan una licencia de Power BI y derechos de lectura sobre el informe o el área de trabajo. Los derechos se conceden en Power BI, no en el CMS.

**Pregunta:** El informe tiene márgenes grises o es demasiado pequeño.

Respuesta: En **Relación de aspecto**, selecciona el formato que tiene la página del informe en Power BI (normalmente 16:9).
