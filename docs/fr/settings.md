# Paramètres

Tous les paramètres se trouvent dans la fenêtre **Intégrer un rapport**, qui
ouvre les paramètres du widget. Elle comporte trois sections.

| Paramètre (section) | Description |
| --- | --- |
| Lien Power BI (contenu) | Obligatoire. Lien d'intégration (`https://app.powerbi.com/reportEmbed?…`), qui contient l'intégralité de `<iframe>`-Code oder die Adresse eines geöffneten Berichts. Auch „Im Web veröffentlichen“-Links (`/view?r=…`), Dashboards und paginierte Berichte gehen. Nur Adressen von Power BI werden angenommen. |
| Titel für Screenreader (Barrierefreiheit) | Name des Berichts für Screenreader, auf der Seite unsichtbar. Voreingestellt: „Power-BI-Bericht“. |
| Seitenverhältnis (Gestaltung) | Breite zu Höhe des Berichtsbereichs: 16:9 (voreingestellt), 4:3, 3:2, 21:9, 1:1 oder 9:16 (Hochformat). |

Blöcke, die vor dem Fenster angelegt wurden, behalten ihre Werte: Sie gelten
weiter, bis sie im Fenster geändert und übernommen werden.
</iframe>
