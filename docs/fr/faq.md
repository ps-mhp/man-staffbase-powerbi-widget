# FAQ

**Question :** « Aucun lien Power BI n'est configuré. Veuillez saisir le lien d'intégration du rapport dans les paramètres du widget. »

Réponse : Le champ **Lien Power BI** est vide. Saisissez le lien comme décrit dans la section « Étape par étape ».

**Question :** « Le lien ne redirige pas vers Power BI. Seuls les liens vers app.powerbi.com (ou vers les clouds Power BI destinés aux administrations publiques et à la Chine) sont autorisés. »

Réponse : Pour des raisons de sécurité, le widget n’affiche que du contenu provenant de Power BI. Vérifiez que le lien commence par `https://app.powerbi.com/` et qu’il a été copié dans son intégralité.

**Question :** « Le lien ne peut pas être intégré. Veuillez sélectionner dans Power BI « Fichier › Intégrer un rapport › Site web ou portail » et saisir le lien qui s’affiche à cet endroit. »

Réponse : Le lien mène bien à Power BI, mais pas à un rapport (par exemple, la page d’accueil ou un lien de partage `/links/…`). Utilisez le lien d’intégration disponible dans le menu **Fichier › Intégrer le rapport**.

**Question :** Une page de connexion ou le message « Accès refusé » s’affiche à la place du rapport.

Réponse : Cela provient de Power BI lui-même. Les lecteurs ont besoin d’une licence Power BI et de droits de lecture sur le rapport ou l’espace de travail. Attribuez les droits dans Power BI, et non dans le CMS.

**Question :** Le rapport présente des marges grises ou est trop petit.

Réponse : Sous **Format d’image**, sélectionnez le format correspondant à la page du rapport dans Power BI (généralement 16:9).
