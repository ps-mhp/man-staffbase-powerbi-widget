# Power BI

Ce widget affiche un rapport Power BI directement sur la page. Il suffit de
disposer du lien d'intégration du rapport provenant de Power BI ; les données, les filtres et les pages du
rapport restent dans Power BI et sont toujours à jour.

## Ce que voient les lecteurs et lectrices

Le rapport s'affiche sur toute la largeur de la colonne, dans le format d'image sélectionné, et peut être utilisé
comme dans Power BI (filtres, pages, plein écran). Power BI vérifie alors les
autorisations : les personnes qui ne sont pas autorisées à consulter le rapport dans Power BI ne voient ici
que le message de connexion ou d'erreur de Power BI. Lors de la première consultation, une
connexion avec le compte d’entreprise peut être nécessaire.

## Ce que vous voyez dans l’éditeur CMS

La même chose que les lecteurs. Si le lien est manquant ou invalide, une
notification grise indiquant la raison s’affiche à la place
du rapport.
