# Perguntas frequentes

**Pergunta:** «Não está configurado nenhum link do Power BI. Introduza o link de incorporação do relatório nas definições do widget.»

Resposta: O campo **Ligação do Power BI** na janela **Incorporar relatório** está vazio. Introduza a ligação conforme descrito em «Passo a passo».

**Pergunta:** «O link não redireciona para o Power BI. Só são permitidos links para app.powerbi.com (ou para as nuvens do Power BI destinadas a organismos públicos e à China).»

Resposta: Por motivos de segurança, o widget apenas apresenta conteúdos do Power BI. Verifique se o link começa por `https://app.powerbi.com/` e se foi copiado na íntegra.

**Pergunta:** «Não é possível incorporar o link. Selecione no Power BI «Ficheiro › Incorporar relatório › Site ou portal» e insira o link aí apresentado.»

Resposta: O link conduz ao Power BI, mas não a um relatório (por exemplo, página inicial ou um link de partilha `/links/…`). Utilize o link de incorporação do menu **Ficheiro › Incorporar relatório**.

**Pergunta:** Em vez do relatório, aparece uma página de início de sessão ou a mensagem «Sem acesso».

Resposta: Isso deve-se ao próprio Power BI. Os leitores precisam de uma licença do Power BI e de direitos de leitura sobre o relatório ou a área de trabalho. Atribua os direitos no Power BI, não no CMS.

**Pergunta:** O relatório tem margens cinzentas ou está demasiado pequeno.

Resposta: Na janela **Incorporar relatório**, em **Proporção da página**, selecione o formato que a página do relatório tem no Power BI (normalmente 16:9).
