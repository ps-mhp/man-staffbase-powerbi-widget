# FAQ

**Question:** “No Power BI link configured. Please enter the report’s embedding link in the widget settings.”

Answer: The **Power BI Link** field in the **Embed Report** window is empty. Enter the link as described in “Step-by-Step.”

**Question:** “The link does not lead to Power BI. Only links to app.powerbi.com (or the Power BI clouds for government agencies and China) are allowed.”

Answer: For security reasons, the widget only displays content from Power BI. Check whether the link begins with `https://app.powerbi.com/` and was copied in its entirety.

**Question:** “The link cannot be embedded. Please select ‘File › Embed Report › Website or Portal’ in Power BI and enter the link displayed there.”

Answer: The link does lead to Power BI, but not to a report (e.g., the home page or a share link `/links/…`). Use the embed link from the **File > Embed Report** menu.

**Question:** A login prompt or “No access” appears instead of the report.

Answer: This is caused by Power BI itself. Readers need a Power BI license and read permissions for the report or workspace. Grant permissions in Power BI, not in the CMS.

**Question:** The report has gray borders or is too small.

Answer: In the **Embed Report** window, under **Aspect Ratio**, select the aspect ratio that the report page has in Power BI (usually 16:9).
