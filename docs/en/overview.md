# Power BI

The widget displays a Power BI report directly on the page. All it needs is
the report’s embed link from Power BI; the report’s data, filters, and pages
remain in Power BI and are always up to date.

## What Readers See

The report is displayed at full column width, in the selected aspect ratio, and can be interacted with
just like in Power BI (filters, pages, full screen). Power BI checks
permissions: Anyone who is not authorized to view the report in Power BI will see
only the Power BI login or error message here as well. The first time the report is accessed,
you may need to log in with your company account.

## What You See in the CMS Editor

The same as readers; editing takes place in the full-screen **Embed Report**
window. If the link is missing or invalid, a gray message explaining the reason appears
instead of the report.
